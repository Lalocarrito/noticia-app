# noticia-app — Tablero de noticias

**Creador:** Josué Martínez — [@Lalocarrito](https://github.com/Lalocarrito)

Tablero de noticias con React y Firebase Firestore: publica avisos (título, contenido y
grupo) y agrega comentarios en tiempo real. Incluye modo claro/oscuro.

## Requisitos y ejecución

- Node.js 18+
- Un proyecto de Firebase con Firestore

```bash
npm install
cp .env.example .env.local   # pon tus credenciales de Firebase
npm start
```

La app queda en http://localhost:3000.
